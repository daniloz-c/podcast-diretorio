faça um site tipo o letterboxd mas voltado para podcasts.
utilize a api do podcastindex.org para buscar podcasts, episodios, etc.

seja um site focado nos podcasts brasileiros.

### features:
- apresentar todos os podcasts brasileiros cadastrados na API
- buscar podcasts
    apresentar todos os episodios, separando por ordem crescente de lançamento (do mais antigo para o mais novo)
- favoritar podcasts
- seguir outros usuários
- criar listas de podcasts
- comentar em podcasts
- curtir podcasts
- avaliar podcasts

# padrões do letterboxd:

- login
- cadastro
- perfil
- pagina de podcast
- pagina de episodio
- pagina de usuario
- feed de atividades

# padrões do podcastindex.org:

- buscar podcasts
- buscar episodios
- buscar categorias
- buscar tags
- buscar usuários
- buscar listas

# padrões do firebase:

- autenticação
- banco de dados
- storage
- notificações
- etc

utize o node js como backend e o react como frontend.

- capa
- nome

- lista de episodios
- botão de favoritar
- botão de seguir
